# Computer-Vision-ROS-Project

This project implements an autonomous mobile robot system capable of searching for, detecting, and approaching a target object using computer vision and classical robotics techniques. The system is developed using ROS and deployed on a TurtleBot platform within a simulated environment.

The robot performs active exploration using search and scanning strategies to locate a coloured target box. Visual perception is handled through camera-based colour detection, while navigation decisions are driven by search algorithms that guide movement, orientation, and target alignment.

Once the object is detected, the robot transitions from exploration to goal-directed behaviour, estimating relative position and autonomously approaching the target while maintaining stable motion. The project integrates perception, decision-making, and control into a cohesive robotic pipeline.

This work demonstrates practical experience with ROS-based systems, vision-guided navigation, and autonomous robot behaviour design, combining computer vision with classical search and planning methods in a real-time robotic environment.
